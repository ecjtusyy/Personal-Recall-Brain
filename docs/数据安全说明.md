# 数据安全说明

本项目把下面两个目录视为不可变的只读资料源：

- `D:\本科期间学习\日记`
- `D:\本科期间学习\考研`

安全边界：

1. 扫描器只用读取模式打开源文件，不包含删除、移动、重命名或写回源文件的代码路径。
2. 数据库、OCR 结果、音频转写、嵌入向量和 Word 内嵌图片副本都只写入项目的 `data/`。
3. 下载的 OpenVINO 模型只写入项目的 `models/`。
4. 源文件消失时，只把数据库记录标为 `missing`，不会对磁盘做反向同步。
5. 打开原文件前会验证路径必须位于配置的资料根目录内。
6. `data/` 与 `models/` 已加入 `.gitignore`，个人内容不会推送到 GitHub。

建议定期备份原始学习资料。数据库属于可重建派生数据，不应替代原始资料备份。
